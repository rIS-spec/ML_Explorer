# ML Explorer

A hands-on collection of **machine learning experiments and implementations** in Python — covering core ML algorithms, model training, evaluation, and comparison across real datasets.

---

## What this covers

| Area | Topics |
|------|--------|
| Supervised learning | Linear regression, logistic regression, decision trees, random forests |
| Model evaluation | Accuracy, precision, recall, F1, confusion matrix, ROC-AUC |
| Data preprocessing | Scaling, encoding, train/test split, handling missing values |
| Model comparison | Side-by-side benchmarking of algorithms on the same dataset |

---

## Tech stack

| Tool | Purpose |
|------|---------|
| Python 3.x | Core language |
| scikit-learn | ML algorithms and evaluation |
| Pandas | Data loading and manipulation |
| NumPy | Numerical operations |
| Matplotlib / Seaborn | Visualisation of results |
| Jupyter Notebook | Interactive experimentation |

## How to run

```bash
git clone https://github.com/rIS-spec/ML_Explorer.git
cd ML_Explorer

pip install scikit-learn pandas numpy matplotlib seaborn jupyter

jupyter notebook
```
